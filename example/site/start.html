For total beginners

Never used GitHub? Start from zero.

You don't need to be a developer, and you don't need to install anything — no VS Code, no terminal. You need three free things and about fifteen minutes. This page gets you from nothing to your first reviewed change, the cheapest way first.

The one question everyone asks

"Do I need VS Code?" No. VS Code is one option among many, not a requirement. Everything below happens in a web browser: your code lives on a website (GitHub), and your "editor" is a chat box you type requests into. An install-nothing path exists, and so does a genuinely free one.

The whole thing, in three pieces

Before the steps, the picture. Building this way needs exactly three things — and a person (you) stays in charge of all of them.

1 · GitHub

A free website that stores your project and remembers every change. Think "Google Docs for code" — your work lives here, in the cloud, not on your laptop. Making an account is free and needs no card.

2 · A copy of this template

archreator is a starting point, not an app you install. One click gives you your own private copy — the architecture skeleton, the skills, the review templates — with its own clean history.

3 · An AI agent

The thing that actually builds. You describe what you want in plain language; it does the work and hands you a change to approve. It runs in the cloud or your browser — you never touch a code editor unless you want to.

That's the Requester → Agent → Reviewer loop this whole project is built around: you request and approve, the AI builds in between. Nothing ships until you say yes.

Set it up: three steps

1

Create a free GitHub account

Go to github.com/signup and sign up with an email. It's free, no credit card. This is the account that will own your project.

2

Make your own copy

Open the archreator template and click Use this template → Create a new repository. Give it a name, leave it Private, hit Create. You now have your own copy — the README's quick start has the same steps with pictures.

3

Point an AI agent at it

Pick one of the agents below and connect it to the repo you just made. That's the whole setup — from here on you just describe changes and review what comes back.

Step 3, expanded: which AI agent?

There are many; here are the two easiest starting points, cheapest first. Both run in your browser — neither needs VS Code or any install. Prices change, so each links its own live plan page; figures here are current at the time of writing (mid-2026).

Free, no card — GitHub Copilot

GitHub's own AI has a free tier (roughly 2,000 code completions and 50 "premium"/agent requests a month) that works right inside github.com and its browser editor — nothing to install. Great for trying the loop without spending a cent.

The catch: the fully hands-off "assign a task, get a finished change back" agent needs a paid Copilot plan; the free tier gives you an agent you steer, capped at a small number of requests per month.

Simplest end-to-end — Claude Code on the web

Go to claude.ai/code, connect your GitHub repo, and type what you want. It works in a cloud sandbox and opens a change for you to review and merge — exactly the Requester → Agent → Reviewer loop, with zero setup on your machine. This is the closest match to how archreator is meant to run.

The catch: there's no free Claude Code tier. The cheapest way in is a Claude Pro plan (about $20/month, which includes Claude Code on the web), or pay-as-you-go API usage that can be very cheap if you only build occasionally.

Already a student or open-source maintainer? You may get the paid tools free.

The GitHub Student Developer Pack gives verified students and teachers Copilot Pro (and other tools) at no cost, and Anthropic runs a free-access program for maintainers of popular open-source projects. Worth checking before you pay for anything.

Our pick for the simplest free start: create the account and the repo (steps 1–2), try GitHub Copilot's free tier in the browser to feel the loop, and move to Claude Code on the web when you want an agent that takes a whole request and hands back a reviewed change end to end.
